# Configuration reference

Package settings are stored in `/etc/amp-panel/amp-panel.env`. For boolean flags,
`true`, `yes`, `on`, and `1` mean true. An empty secret means unconfigured, not a
safe production default.

## Host and profile

| Variable | Default | Meaning / constraints |
| --- | --- | --- |
| `AMP_PANEL_CONFIG_VERSION` | `2` | package configuration format version |
| `AMP_PANEL_PORT` | `8000` | web port, 1024–65535 |
| `AMP_PANEL_DATA_DIR` | `/var/lib/amp-panel` | data directory; paths below `/mnt`, `/media`, and `/srv` are also allowed |
| `DEVICE_PROFILE` | `amplifier` | `amplifier` or `fts-ls` |
| `DEVICE_NAME` | generated | syslog/SNMP device identifier |
| `MDNS_HOSTNAME` | host name | Avahi label without `.local`, up to 63 characters |
| `INITIAL_ADMIN_USERNAME` | `admin` | first Administrator, 1–128 allowed characters |
| `TZ` | `Europe/Warsaw` | process/system timezone |

The application parser recognizes aliases `amp`, `optical-amplifier`, `fts_ls`,
and `laser-station`, but new configurations should use canonical values only.

## Device connection

| Variable | Default | Meaning / constraints |
| --- | --- | --- |
| `SERIAL_PORT` | `/dev/ttyACM0` | `ttyACM`, `ttyUSB`, `ttyS`, `ttyO`, or `/dev/serial/by-id/...` |
| `SERIAL_BAUDRATE` | 9600/115200 | 9600 for amplifier, 115200 for FTS-LS |
| `GAIN_SET_MIN` | none | required with `GAIN_SET_MAX` for amplifier |
| `GAIN_SET_MAX` | none | finite and greater than the minimum |
| `FTS_LS_USERNAME` | `appadmin` | station-console user |
| `FTS_LS_PASSWORD` | empty | console password; required if the station requests one |
| `FTS_LS_POLL_SECONDS` | `10` | 2–3600 in the configurator |
| `FTS_LS_FREQUENCY_MIN_GHZ` | `194392.6` | central-frequency lower bound |
| `FTS_LS_FREQUENCY_MAX_GHZ` | `194405.6` | greater than the lower bound |

## Data and history

| Variable | Default | Meaning / constraints |
| --- | --- | --- |
| `DATABASE_FILE` | `<data-dir>/measurements.db` | SQLite file |
| `PERSISTED_STATE_FILE` | `<data-dir>/persisted_state.json` | persistent UI settings |
| `DATABASE_MAX_RECORDS` | `0` | 0 means unlimited; UI allows up to 10,000,000 |
| `HISTORY_MAX_POINTS` | `2000` | history-view point limit, programmatic minimum 100 |

## Login and sessions

| Variable | Default | Meaning |
| --- | --- | --- |
| `LOGIN_MAX_ATTEMPTS` | `5` | attempts from one IP within the window |
| `LOGIN_WINDOW_SECONDS` | `300` | login-limit window |
| `SESSION_MAX_AGE_SECONDS` | `43200` | session/cookie lifetime |
| `SESSION_COOKIE_SECURE` | `false` | send cookie only over HTTPS |
| `TRUST_PROXY_HEADERS` | `false` | trust client IP supplied by a proxy |

## Syslog

| Variable | Default | Meaning / constraints |
| --- | --- | --- |
| `SYSLOG_ENABLED` | `true` | local event sending |
| `SYSLOG_HOST` | `127.0.0.1` | local receiver |
| `SYSLOG_PORT` | `514` | receiver UDP port |
| `SYSLOG_APP_NAME` | `amp-panel` | application tag |
| `SYSLOG_FACILITY` | `16` | local0 by default |
| `SYSLOG_TIMEZONE` | `Europe/Warsaw` | syslog-header timezone |
| `SYSLOG_HEARTBEAT_SECONDS` | `300` | 0 disables; UI range 10–86400 |
| `SYSLOG_EXPORT_FILE` | `/var/log/amp-panel/amp-panel.log` | export and alarm-history source |
| `REMOTE_SYSLOG_ENABLED` | `false` | forwarding through rsyslog |
| `REMOTE_SYSLOG_HOST` | empty | required when enabled |
| `REMOTE_SYSLOG_PORT` | `514` | 1–65535 |
| `REMOTE_SYSLOG_PROTOCOL` | `tcp` | `tcp` or `udp` |

## SNMP, NTP, and RADIUS

| Variable | Default | Meaning / constraints |
| --- | --- | --- |
| `SNMP_PORT` | `1161` | agent UDP port, fixed in the UI |
| `SNMP_COMMUNITY` | generated by configurator | initial community; UI requires at least 12 characters |
| `NTP_SERVER` | `tempus1.gum.gov.pl` | primary time server |
| `NTP_SERVER_FALLBACK_IP` | `194.146.251.100` | fallback address |
| `NTP_PORT` | `123` | UDP port |
| `NTP_TIMEOUT_SECONDS` | `3` | probe timeout |
| `NTP_CACHE_SECONDS` | `15` | status cache duration |
| `RADIUS_SERVER` | empty | server host, required for login |
| `RADIUS_PORT` | `1812` | authentication port |
| `RADIUS_SECRET` | empty | required shared secret |
| `RADIUS_TIMEOUT_SECONDS` | `3` | per-request timeout |
| `RADIUS_RETRIES` | `1` | retry count |
| `RADIUS_NAS_IDENTIFIER` | `DEVICE_NAME` | NAS identifier |

## Internal package paths

`NETWORK_AGENT_SOCKET` defaults to `/run/amp-panel/network-agent.sock`.
Do not modify this value from the dashboard.
