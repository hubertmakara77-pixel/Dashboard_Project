# Glossary

| Term | Meaning in this project |
| --- | --- |
| Amp Panel | the web application and system package |
| amplifier | optical-amplifier device profile |
| FTS-LS | Frequency Transfer System — Laser Station |
| UL | physical uplink module in the FTS-LS station |
| P1–P7 | seven physical station module slots |
| UNEQUIPPED | slot without an installed module |
| TEC | thermoelectric cooler and its temperature controller |
| gain set | requested gain value |
| gain actual | gain calculated or reported by the device |
| gain delta | set gain minus actual gain |
| snapshot | complete FTS-LS status at one point in time |
| acknowledge | record that an alarm was seen; does not close it |
| OPEN / CLEARED | alarm opening and automatic recovery events |
| heartbeat | periodic syslog event confirming process operation |
| network checkpoint | temporary NetworkManager change rolled back without confirmation |
| RADIUS | external password-verification server |
| community | SNMP v2c shared secret |
| WAL | SQLite write-ahead log enabling concurrent reads |
| mDNS | local `<host>.local` name resolution through Avahi |
